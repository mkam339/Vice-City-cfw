# Vice City — موقع ومتجر السيرفر (كل الملفات في مجلد واحد)

## التشغيل
    node server.js
- يتطلب Node.js 18 أو أحدث، بدون npm install.
- أول تشغيل يطبع كلمة مرور المالك (المستخدم: owner)، أو حدّدها بمتغير البيئة OWNER_PASSWORD.
- الموقع على المنفذ PORT (الافتراضي 3000) ولوحة التحكم على /admin.

## الملفات (كلها في نفس المجلد)
server.js الخادم | index.html + app.js الموقع | admin.html + admin.js اللوحة | style.css + fx.js التصميم | rules.json القوانين | logo.png الشعار
db.json يُنشأ تلقائياً (كل البيانات — خذ منه نسخة احتياطية) | up-*.png صور المنتجات المرفوعة تُحفظ بنفس المجلد.
ملفات الخادم (server.js, db.json) محمية ولا تظهر للزوار.
